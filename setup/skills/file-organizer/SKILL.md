# File Organizer

Quando l'utente vuole organizzare file o cartelle:

## Regole
- MAI cancellare file senza chiedere conferma
- Mostra sempre un'anteprima dei cambiamenti PRIMA di farli
- Crea backup se richiesto

## Processo
1. Analizza la struttura attuale
2. Proponi una nuova struttura organizzata
3. Aspetta conferma dell'utente
4. Esegui i cambiamenti

## Convenzioni di nomi
- Cartelle: kebab-case (es: `miei-documenti`)
- File: descrittivi e con data se necessario (es: `report-vendite-2026-03.pdf`)
- Niente spazi nei nomi — usa trattini
